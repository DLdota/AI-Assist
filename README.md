# AI Assistant for IDA Pro

**AI-помощник для обратной разработки и анализа кода непосредственно в IDA Pro.**

Плагин интегрирует большие языковые модели (LLM) в рабочий процесс IDA Pro и помогает анализировать декомпилированный код, исследовать связи между функциями, восстанавливать назначение структур и переменных, сравнивать версии функций и генерировать предложения по улучшению именования.

Поддерживаются локальные модели через **Ollama** и облачные модели через **OpenAI-compatible API**.

## Возможности

### 1. Глубокий анализ функций (Deep Scan)

<img width="947" height="1167" alt="image" src="https://github.com/user-attachments/assets/4c9747f0-d474-4df5-8ea0-ca42f4a65ebf" />

Многоуровневый анализ выбранной функции с использованием контекста из базы IDA.

Доступны четыре уровня анализа:

| Уровень | Что анализируется |
|---|---|
| Поверхностный | Выбранная функция |
| Базовый | Функция, Xref и непосредственные вызовы |
| Глубокий | Рекурсивный граф вызовов, типы, структуры и дизассемблер |
| Очень глубокий | Дополнительно исследуются callback и связи через указатели на функции |

В ходе анализа собирается дополнительный контекст:
- Псевдокод и информация о функции.
- Входящие Xref.
- Вызываемые функции и граф вызовов.
- Типы и предполагаемые поля структур.
- Строки, глобальные переменные и другие доступные сведения.

Результаты включают предполагаемое назначение функции, варианты именования, анализ переменных, подтверждённые факты и гипотезы.

### 2. Анализ псевдокода

Отдельный режим для исследования логики декомпилированной функции.

Помогает:
- Объяснить назначение функции.
- Разобраться в условиях и ветвлениях.
- Найти потенциально интересные участки кода.
- Предложить более понятные имена локальных переменных.
- Получить рекомендации по дальнейшему исследованию.

### 3. Чат с ИИ

<img width="932" height="967" alt="image" src="https://github.com/user-attachments/assets/ec69c75a-dbba-431c-93b0-cf8b32403158" />

Интерактивный чат с контекстом текущей функции.

Можно задавать вопросы о коде, передавать собственные фрагменты псевдокода и продолжать обсуждение в рамках одной истории.

Особенности:
- Автоматическое получение контекста выбранной функции.
- Работа с Xref и информацией из базы IDA.
- Сравнение текущей функции с ранее сохранённой или вставленной версией.
- Анализ изменений смещений и полей структур.
- История переписки сохраняется в базе IDB.
- Отображение Markdown, таблиц, блоков кода и Diff.

**Сравнение версий функций**

При передаче старой версии функции плагин может предварительно выделить изменения и передать их модели для анализа.

В ответе модель должна:
- Составить таблицу старых и новых смещений.
- Рассчитать разницу между смещениями.
- Указать предполагаемое назначение полей, слотов vtable, индексов массивов и констант.
- Привести строки кода, подтверждающие выводы.
- Выявить возможные изменения структуры.
- Перечислить добавленные и удалённые вызовы, а также изменения логики.

Предположения должны отделяться от подтверждённых фактов.

### 4. Генерация C++-структур

Создание предполагаемого описания C++-структуры на основе выбранной переменной и доступного контекста декомпиляции.

Помогает быстрее восстанавливать внутреннее устройство объектов и анализировать использование полей.

### 5. Применение предложений ИИ

Результаты анализа представлены в виде предложений, которые можно просмотреть и выбрать перед применением.

Поддерживаются предложения по:
- Переименованию функций.
- Переименованию локальных переменных.
- Изменению типов локальных переменных.
- Изменению прототипов.
- Добавлению комментариев к функциям и переменным.

Перед применением можно проверить и выбрать необходимые изменения.

### 6. Локальные и облачные модели

Плагин поддерживает два варианта подключения:

**Ollama**
- Запуск моделей локально.
- Настройка адреса сервера.
- Выбор модели.
- Настройка контекста, температуры и лимита генерации.

**OpenAI-compatible API**
- Подключение облачных моделей через совместимый API.
- Настройка URL, API-ключа и названия провайдера.
- Выбор модели и параметров генерации.
- Поддержка пользовательских дополнительных JSON-параметров API.

Можно переключаться между локальным и облачным профилями.

### 7. Дополнительные возможности

- Кэширование результатов анализа в базе IDB.
- Повторное использование сохранённых результатов.
- Потоковая генерация ответов.
- Отображение статистики токенов, времени выполнения и стоимости запросов, если провайдер предоставляет необходимые данные.
- Настраиваемая глубина анализа и лимиты вывода.
- Настройка языка ответов модели.
- Светлая и тёмная темы интерфейса.
- Несколько цветовых схем псевдокода.
- Настройка сетевого подключения и прокси.

## Установка

1. Скачайте или клонируйте репозиторий.
2. Скопируйте `ai.py` и папку `ai_assistant` в каталог `plugins` вашей установки IDA Pro.
3. Запустите IDA Pro.
4. Откройте плагин через меню **Edit → AI Assistant** или используйте сочетание `Ctrl + Alt + A`.

Для работы необходима настроенная модель Ollama либо подключение к OpenAI-compatible API.

## Настройка

Откройте настройки плагина и выберите способ подключения.

**Для Ollama:**
- Укажите URL сервера (по умолчанию `http://127.0.0.1:11434`).
- Выберите установленную модель.
- Настройте параметры генерации.

**Для облачного API:**
- Укажите название провайдера.
- Введите API URL.
- Укажите API-ключ.
- Выберите модель.

Дополнительно можно настроить язык ответов, глубину Deep Scan, лимиты токенов, сетевой прокси и поведение модели в чате.

## Требования

- IDA Pro 9.4.
- Python и PySide6, используемые окружением IDA Pro.
- Ollama или доступ к OpenAI-compatible API.
- Доступ к декомпилятору Hex-Rays для работы с псевдокодом.

## Важное замечание

Плагин использует ИИ для анализа и предлагает варианты интерпретации кода. Результаты модели не являются гарантированно правильными.

Особенно внимательно следует проверять:
- Предполагаемые типы и размеры полей.
- Смещения и устройство структур.
- Назначение функций и переменных.
- Результаты сравнения разных версий кода.

Применяйте изменения только после проверки в IDA.
